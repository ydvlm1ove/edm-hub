# EDM-Hub

EDMの楽曲や動画へのアクセスを快適にし、お気に入りを記録できるHUBサイトです。

## プロジェクトの概要

- **開発背景:** EDM専門のサイトが少ないこと、YouTube動画へのアクセスが面倒なこと、自分のお気に入りを記録できる環境が欲しかったことから、すべてを一元管理できるHUBを目指して制作を開始しました。
- **現在のステータス:** 開発初期段階（バックエンド・フロントエンドの基盤構築中...）

## 使用技術

### フロントエンド
- HTML5 / CSS3
- JavaScript (Vanilla JS / Vue.js CDN版)
- PWA (manifest.json)

### バックエンド
- Python 3.13
- Flask

### データベース
- MySQL

### バージョン管理・公開
- Git / GitHub (Publicリポジトリ)
